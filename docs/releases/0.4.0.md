# WOS 0.4.0

- Add native offline Go `wos skill` installation, updates, verification and uninstall for the five canonical WOS agent skills.
- Distribute native Go wos/wosctl CLI to Linux and Windows x64 through a standalone npm package; integrate versioning and immutable release verification.

Packages: Linux WOS service with wosctl, cross-platform native WOS CLI for Linux/Windows x64 and five portable skills. Service target: Linux amd64. Client assets: Linux amd64 and Windows amd64; actual matching native test receipts are required before publication. Skills require Node >=22 and a compatible runtime. Cross-building and release preparation do not certify Windows or registry publication.

Initial standalone CLI npm publication target: `@woobeai/wos-cli@0.4.0` (the scope of the authenticated npm publisher). Source/package/host receipts must match the final release commit; no other registry scope is implied by this CLI-only publication.
