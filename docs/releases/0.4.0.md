# WOS 0.4.0

- Add native offline Go `wos skill` installation, updates, verification and uninstall for the five canonical WOS agent skills.
- Distribute native Go wos/wosctl CLI to Linux and Windows x64 through a standalone npm package; integrate versioning and immutable release verification.

Public npm identity: `wosctl@0.4.0`, installed with `npm install -g wosctl@latest` once registry availability is verified. It supplies native Go `wos`/`wosctl`, including `wos skill install --agent codex`. There is no separately installed skills package. Native server support: Linux amd64; native CLI support: Linux/Windows amd64 with exact-source receipts. Prepared is not published.
