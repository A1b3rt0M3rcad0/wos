## Reproduce the demonstration image

Install the existing browser development dependencies under `tests/web`, provide Chromium and `ffmpeg`, then run:

```sh
WOS_TEST_CHROMIUM_PATH=/path/to/chromium node tools/documentation/render-quickstart.mjs
```

The renderer consumes [the original recording](../examples/quickstart/demo.cast). It writes [the GIF](images/quickstart.gif) and [rendering metadata](images/quickstart.json). [Execution provenance](../examples/quickstart/demo.provenance.json) records the exact script and binary hashes. The captured binary reports unknown embedded VCS metadata, so the record does not claim stronger binary-to-source attestation.

The [image manifest](images/assets.json) distinguishes original owner artwork, the byte-identical logo alias, existing product screenshots, static baseline/version badges, and rendered output. The CI badge is explicitly the live **master** workflow badge, rather than an assertion about this documentation commit. The local GFM preview uses an actual fetched CI SVG response, served from cache to the browser; version badges and all content images are local files.

## Limits

The public image contains the earlier released interface. Branch screenshots and source examples are labeled separately. Native macOS/ARM distributions, container emulation, other browser engines, physical devices, manual screen-reader use, production deployment and 1.0 certification are outside this check.

The full Go, browser, race, native-platform, and packaging suites are not rerun locally for this documentation follow-up. Existing CI workflows apply to the new PR. No new release, container publication, security-setting change, deployment, or PR merge is performed.
