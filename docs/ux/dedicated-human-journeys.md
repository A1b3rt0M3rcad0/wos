# Dedicated human journeys

Common actions are explicitly named by human intent. The technical command catalog validates transport compatibility; it no longer generates common forms or the common action menu. A separate Developer console requires workspace administration permission. Signed execution and review remain external-profile operations.

- **Outcome:** name, desired result and optional description save a persisted Draft; activation is a separate decision.
- **Objective:** a verifiable intermediate condition, optional searched parent, required-for-outcome flag and priority.
- **Task:** bounded work, optional searched Objective, initial Backlog/To do, readable instructions/constraints/deliverables/scope hints, multi-context references and local-time schedule.
- **Roadmap:** visual phases, milestones and typed references with stable internal keys, hierarchy and move controls. Save a Draft, review changes with a reason, publish an immutable revision, then explicitly activate it. Removing references never deletes Tasks.
- **Verification:** register source-backed Evidence, then assess an exact criterion definition revision. Waived is not verified. Unsigned contract assessments retain the exact submitted material identity.
- **Issues:** report a problem independently of its blocking impact, or explicitly use the compound operation. Resolving an Issue does not release a Blocker; releasing impact requires confirmation.
- **Conflict:** preserve local inputs, load a comparison, explicitly confirm content edits against newly observed CAS versions. Transition/assessment authority is never silently rebased.
- **Uncertain response:** serialize one scoped intent and retain its exact bytes/key for replay. Editing is locked during uncertainty; committed writes whose refresh fails are not treated as uncommitted retries.

Reference pickers query authorized server metadata with typed scope, ID resolution, debounced search, generation/cancellation guards, pagination, duplicate-name context, selected-ID retention and keyboard controls. Stale cursors require explicit reload. Execution controls also use current operational projection and matching lease holder; the API remains authoritative.

Ten new real-server human journeys cover these flows without choosing API command IDs, including 1,001 Tasks/Evidence and stale pagination. Six compatibility journeys retain their transport/domain regression coverage, using the explicit Developer console where they exercise technical catalog shapes. Manual usability and screen-reader validation remain pending by owner decision.
