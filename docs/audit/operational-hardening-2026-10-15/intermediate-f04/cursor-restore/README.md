# Continuity cursor restore regression

SQLite consistent backup to a new file and PostgreSQL dump/restore to a new empty database preserve both old digest cursors and new v2 keyset cursors. The direct bounded/no-hydration journey compares the complete continuation JSON before/after restore, resumes consecutive pages, retains evaluation time/revision and then checks long external references, wrong scopes, missing rows and post-write cursor invalidation. The derived lease-expiry journey restores while leases are active, advances the read clock without a mutation, resumes the old frozen operational page and observes expired leases only in a fresh projection. Memory retains its same pure-time semantic test. Both SQL adapters and Memory pass the applicable race journeys; PostgreSQL ran actual empty-database restore with WOS_TEST_POSTGRES_CONTAINER, not a restart-only fallback.
