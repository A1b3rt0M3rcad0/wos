# E18 — Add versioned permission templates

Implemented in commit `c7b3b73a2985c72e36e9ea5811964003d4f0c7f3` on `fix/workspace-operational-density`.

The application now exposes six immutable, versioned permission templates: reader, planner, executor, reviewer, issue operator, and administrator. Selection materializes a detached, concrete permission list. Edited lists become custom and lose misleading template provenance; unsupported versions are rejected rather than silently upgraded. Preview intersects the chosen set with the Principal's Namespace grant and optional CredentialPolicy. These helpers do not authorize commands or replace server-side checks.

English copy describes each template and clarifies that templates are not inherited roles, do not bypass review, and cannot create reviewer independence between credentials for the same Principal. Credential issuance and persistence remain E19 work.
