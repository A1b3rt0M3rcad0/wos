Implementation commit: `88ed20f3f6a41e4ed0d1ca67d8bae320e8642a2f`.

Migration `0037_operational_profile.sql` adds the Outcome operational profile and Objective completion mode/cycle without changing migrations 0035 or 0036. Upgraded records default to `compatibility_v1`, `manual`, and cycle `1`. SQLite stores the unsigned cycle as canonical decimal `TEXT`; PostgreSQL uses `NUMERIC(20,0)`. Both adapters persist the fields through aggregate CRUD and the compact workspace, focal, and continuity projections. Memory storage enforces the same cross-aggregate configuration rule.

The adapters reject an Objective `automatic` completion mode unless its owning Outcome has the compatible operational-v2/strict-work policy, and reject Outcome policy changes that would invalidate an existing Objective. Tests cover defaults for upgraded rows, enum/range constraints, expected-version conflicts, stale policy changes, memory round trips, and persistence after reopening the database.
