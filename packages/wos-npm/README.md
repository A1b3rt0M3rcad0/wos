# Historical service npm wrapper

This directory is retained as a compatibility fixture and is not an active npm publication target. The single public package is `wosctl`:

```sh
npm install -g wosctl@latest
wos skill install --agent codex
```

Use native Linux archives, Docker Compose or the Linux Go `wos` executable for service deployment. See [public package](../wos-cli-npm/README.md) and [operations](../../docs/operations.md). Historical scoped package versions were not confirmed published; source files do not establish registry availability.
